# Customer Churn Prediction & Retention Dashboard

**Client:** E-Commerce DTC Brand  
**Role:** Data Scientist  
**Stack:** PySpark, Snowflake, Random Forest, Streamlit, GitHub Actions

## Challenge
The client had a 30% monthly churn rate with no early warning system. The marketing team was reactive, not proactive.

## Solution
Engineered a PySpark pipeline to process 5M+ user sessions, built a Random Forest classifier predicting churn probability 14 days in advance, and delivered a Streamlit dashboard for the marketing team.

## Result
- Retained **18%** of at-risk customers in Q1
- Generated **$120K** in recovered revenue
- Dashboard used daily by 6 non-technical team members

## Key Skills
- Big Data Processing (PySpark, Snowflake)
- Classification (Random Forest)
- Dashboarding (Streamlit)
- CI/CD (GitHub Actions)
